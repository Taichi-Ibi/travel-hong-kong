# Logistics — 移動・荷物・時間・空港の設計

**作成日**: 2026-05-09
**担当**: Logistics agent
**通貨表記**: HK$ = 香港ドル（参考レート目安: 1 HK$ ≈ 19〜20円）

---

## 0. 全体方針

- **夫は受託手荷物 0kg・機内持ち込み 0kg（身の回り品1個のみ）**、妻は受託 20kg。スーツケースは妻側のみ＝**実質1個運用**。
- 出発が **5/12(火) 02:20 HND** の深夜便なので、移動・チェックインは **5/11(月) 夜のうちに完了** させるのが大原則。
- 復路は 17:35 HKG 発。**5/16(土) 12:00 のチェックアウト後、空港到着は最遅でも 15:30** を目標。
- 香港側は **オクトパスカード（八達通）必須**。MTR・バス・スターフェリー・コンビニ全てこれ1枚で完結。Apple Pay 版も可。
- 雨予報（5/13〜16）が強いので折りたたみ傘・撥水アウターは身の回り品に常備。

## 1. 5/11(月) 夜 〜 5/12(火) 早朝：自宅 → HND → HKG → ホテル

### 1-1. 自宅 → 羽田空港 第3ターミナル

- **推奨ルート: 京急利用**
  - 最寄り駅（東急多摩川線）→ 蒲田 → 京急蒲田 → 羽田空港第3ターミナル
  - 京急蒲田 → 第3ターミナル: エアポート急行で **約7分・300円台**
  - 平日終電（京急蒲田発・空港方面）は **0:15 ごろ**
- **目標到着時刻: 5/11(月) 23:00 までに第3ターミナル**
  - 香港エクスプレスのチェックインは出発の 3 時間前から（= 5/11 23:20 ごろ）。**受託手荷物のドロップ列が混む前に並びたい**ので 23:00 着が安全圏。
- **代替（疲労時・荷物多い時）**
  - タクシー: 自宅 → HND 第3T で **2,500〜3,500円・15〜20分**
  - 京急蒲田までは Uber/タクシー、そこから京急 1 駅、もアリ

### 1-2. チェックイン・出国・搭乗（5/11 23:00 〜 5/12 02:20）

- **23:00–23:20**: 第3T 出発フロア到着、UO（香港エクスプレス）カウンター位置確認
- **23:20頃**: チェックインカウンター オープン → **妻の受託 20kg を預ける**
  - 夫は受託なし＝列に並ぶ必要なし。妻のみカウンターへ。
  - **重量は事前に自宅で計量**（超過時は 1kg 単位で高額課金）
  - ※身の回り品（夫1個・妻1個）のサイズ・重量規定は搭乗前に再確認
- **24:00頃**: 保安検査 → 出国審査
- **0:30頃まで**: 制限エリア内でラウンジ or ベンチ。深夜帯はレストラン閉店が多い → **国内側で軽食を済ませておく**
- **01:50**: 搭乗開始（出発の30分前目安）
- **02:20 離陸** → 機内で就寝推奨（フライト約4時間40分）

### 1-3. HKG 到着 → 入境 → ホテル（5/12 06:00 〜 09:00 目安）

- **06:00 HKG 着陸** → 接続バス／徒歩で入境ホール
- **06:15–06:45**: 入境審査（早朝便はやや混雑、所要 15〜30分）
- **06:45–07:15**: 受託手荷物受取 → 税関 → 到着ロビー
- **オクトパスカード調達**: 到着ロビーの MTR カウンター or 7-Eleven で購入／チャージ。Apple Pay 八達通の事前登録でも可。
- **07:15–08:30 ホテルへ移動 — 推奨3案**

#### A案: MTR（最速・最安・推奨）

- 機場（Airport）→ **Airport Express で香港駅** 約 24分・**HK$120**（オクトパス）
- 香港駅 → 中環 → **港島線で天后駅**（中環で乗り換え、約15分・HK$5前後）
- 合計: **45〜55分・約 HK$125（≒ 2,500円）／人**
- ※始発は 5:54 ごろ、6:00 着陸でも余裕で利用可

#### B案: シティフライヤー A11（乗換なし・荷物に優しい）

- 空港バス停 → **A11 で天后／銅鑼灣エリア直行**
- 始発 05:10、20分間隔、所要 **70〜90分**、**HK$41.9 ／人**
- 早朝で道が空いていれば 60分強で着くことも。**スーツケース1個ありなのでこちらが楽**
- 降車目安: 「天后廟道」「興発街」付近 → ホテルまで徒歩 5〜10分

#### C案: タクシー（最速ドアtoドア・雨/疲労時の保険）

- 空港 → 銅鑼灣エリア（HK 島）: **HK$350〜400・40〜50分**
- トンネル料金（追加 HK$30 程度）込み
- 4人乗りタクシー（赤）を利用、Uber も可

→ **第一候補は B案（A11バス）**。早朝で疲労があり、スーツケース運搬・乗換負担を最小化できる。雨でなければ A11 で。

### 1-4. ホテルでの荷物預け（5/12 08:30 頃）

- **TUVE Hotel: 24時間フロント・荷物預かり可**（チェックイン 15:00〜より前でも預けられる）
- 預けるもの: スーツケース1個（妻の受託分）
- **手元に残すもの**:
  - パスポート・財布・スマホ・モバイルバッテリー
  - 折りたたみ傘・薄手の上着（雨予報日対策）
  - 当日観光に必要な現金少額・オクトパス
  - 充電ケーブル・常備薬
- 朝食 → 観光開始は **9:00 以降**。早朝チェックイン待ちで疲労が強い場合は、空港の Plaza Premium ラウンジで仮眠（要別料金、3時間 HK$300〜）も検討余地。

## 2. 5/12(火) 〜 5/15(金)：滞在中の移動指針

### 2-1. 移動手段の使い分け

| シーン | 推奨手段 | 補足 |
|---|---|---|
| MTR沿線（中環・尖沙咀・旺角・銅鑼灣など） | **MTR** | 港島線 天后駅からどこへも30分以内、HK$5〜15 |
| 短距離（2km以内・天后〜銅鑼灣・北角） | **徒歩 or トラム（叮叮車）** | トラム HK$3 均一。雨ならMTR |
| 山頂（ピーク）・南区（赤柱・浅水湾） | **バス or タクシー** | ピークトラムは並びが長い。バス 15・6 系統が便利 |
| 雨天時・夜遅く・荷物多い時 | **タクシー（赤）** | 初乗り HK$29、市内移動 HK$50〜100 が目安 |
| 九龍 ↔ HK島 横断（観光的に） | **スターフェリー** | HK$5 前後、ビクトリアハーバー越え 8分 |

### 2-2. 各日の天気を踏まえた指針（weather.md より）

- **5/12(火)** 曇り 31℃ 降水8% → **屋外OKの最良日**。ピーク／南区／離島など晴れ前提プランをこの日に集約
- **5/13(水)** 雨 30℃ 降水37〜48% → 屋内寄り（美術館・ショッピング・アフタヌーンティー）
- **5/14(木)** 雷雨 28℃ 降水78% → **完全屋内デー推奨**。M+、香港故宮文化博物館、PMQ などに集中
- **5/15(金)** 雷雨 27℃ 降水65〜74% → 屋内＋短距離移動。深水埗・上環など徒歩圏で完結する街歩き
- **共通**: 折りたたみ傘・薄手のレインジャケットは毎日携帯。MTR・モール接続が発達しているので、地下／屋根伝いに動ける動線を組む

### 2-3. オクトパスカード運用

- 初日にチャージ HK$200／人。1〜2回 HK$100 ずつ追加チャージで5日間カバー可能
- 残高は帰国前に MTR カウンターで払い戻し可（HK$11 の手数料）／次回訪問用に保持もOK

## 3. 5/16(土)：チェックアウト → 空港

### 3-1. タイムライン

| 時刻 | 行動 |
|---|---|
| 〜09:00 | ホテルで朝食、最終パッキング |
| 09:00–11:30 | **荷物を持たずに最後の観光**（天后・銅鑼灣エリア徒歩圏 or ホテル近隣のカフェ）。雨なら Times Square / Hysan Place などモール直行 |
| 11:30 | ホテル戻り、最終チェック |
| **〜12:00** | **チェックアウト（厳守）** → スーツケースをフロントに再預け |
| 12:00–14:30 | 銅鑼灣／天后エリアでランチ＋軽い買い物。**重い物は買わない／買うなら空港で** |
| 14:30 | ホテル戻り、預けたスーツケースをピックアップ |
| 14:30–14:45 | **天后駅から空港へ向けて出発** |
| 14:45–16:00 | 移動（手段は下記） |
| 16:00 | HKG 到着・チェックイン開始（出発90分前以上を確保） |
| 16:35頃 | UO カウンターで妻の受託預け、保安・出国 |
| 17:35 | UO622 離陸 |

### 3-2. 復路の空港移動 — 推奨

**第一候補: A11 バス（乗換なし・荷物に優しい・座れる）**
- 銅鑼灣（軒尼詩道 or 維多利亞公園付近）→ HKG: 約 70〜90分・**HK$41.9／人**
- 14:30 発であれば 16:00 前後に空港着。**金曜雷雨明けで道路状況が読めない場合はバッファを30分追加**

**第二候補: MTR + Airport Express**
- 天后 → 中環（港島線）→ 香港駅（徒歩接続）→ Airport Express → HKG
- 所要 **40〜45分・HK$125／人**
- バスより速い・読みやすい。ただし乗換2回＋スーツケース運搬あり
- **In-Town Check-in（香港駅で前日／当日のチェックイン＋荷物預け）はLCC各社で対応外のことが多いので UO は要確認**。利用不可なら通常のAirport Expressのみ。

**第三候補: タクシー**
- 銅鑼灣 → HKG: HK$350〜400・40〜50分
- 雷雨で道路が不安定な時、または荷物が増えた時の保険

→ **天気が悪化していなければ A11**、**遅延しているか雷雨が強ければ MTR + Airport Express**。

### 3-3. 復路チェックインの注意

- UO622 のチェックイン締切は出発の **60分前 = 16:35**
- 受託手荷物（妻の20kg）は出発 **45分前 = 16:50** までにドロップ完了
- **遅くとも 16:00 に空港着**を死守。バス利用なら **14:30 発のバス**、MTR なら **15:00 発の Airport Express** を最終ライン。
- 香港土産（食品・お茶など）は受託に詰める。夫の機内持ち込みは0kgなので液体・かさばる物は妻の受託へ集約。

## 4. 荷物まとめ（夫＝身の回り品1個運用の前提整理）

### 夫の身の回り品（機内持ち込み代替）に入れるもの

- パスポート、財布、スマホ、AirPods
- モバイルバッテリー（10000mAh 程度・100Wh以下）
- 充電ケーブル（USB-C, Lightning）
- 常備薬（少量）
- 着替え1セット（Tシャツ・下着・靴下）※不安なら
- 折りたたみ傘（小型）
- ※**液体物 100ml 以下・透明袋必須**、ナイフ・モバイルバッテリー受託預け不可は通常通り

### 妻の受託（20kg）に集約すべきもの

- 二人分の衣類（4泊分＋雨で濡れた時用の予備）
- 化粧品・スキンケア（液体物本体）
- ドライヤー（ホテル備付ありの想定で省略可）
- 香港で買う土産（飲茶用茶葉・菓子など）
- 帰国時に膨らむ余地を 5kg 程度残しておく＝**出発時は 15kg 目安**を推奨

### 注意

- 夫は **機内持ち込み 7kg 制限のキャリーバッグNG**。リュック1個（45×36×20cm 以内・身の回り品扱い）まで。
- 念のため **ノートPCを夫が持つなら**、リュック内に収まるサイズで身の回り品1個カウントの範囲内か事前確認。

## 5. リスク & コンティンジェンシー

| リスク | 対応 |
|---|---|
| 5/11 京急遅延・終電逃し | タクシーに即切替。自宅 → HND 直行で 3,500円目安 |
| HKG 早朝の入境混雑（6:00 便集中） | バッファとして 90分を見込み、A11 始発 7:30 ごろ乗車前提 |
| 5/14〜16 雷雨で交通遅延 | 復路はバスより MTR+Airport Express を優先。タクシー予算 HK$400 を予備で確保 |
| 妻の受託超過 | 出発前夜に体重計で計量、20kg 厳守。超過なら夫の身の回り品に分散 |
| ホテル早朝荷物預け不可 | 銅鑼灣 MTR 駅近くの LuggageHero／Nannybag（HK$30〜/日）を予備手段として記憶 |
| 復路 UO622 遅延／欠航 | 香港エクスプレスアプリで通知 ON。深夜羽田着のため帰宅手段（タクシー or NearMe 1,980円/人）も事前イメージ |
